# Additions

Create an additional view that does the following:

- Takes each token's HEX value, converts it to RGB
- Plots each converted value on an 3d coordinate graph where (r,g,b) = (x,y,z)
- The plotted point should be the color of its represented values
- Option to plot as spheres or cubes
- Option to display the path of plotting:
    - Points connect by a line in the order in which they were plotted.
- Should display as a 3d view that can be manipulated.
